# Creative Studio - Design Agency Landing Page

A modern, responsive landing page for a design agency featuring smooth animations, beautiful gradients, and an engaging user experience.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean, contemporary design with gradient accents
- **Smooth Animations**: Scroll-triggered animations and parallax effects
- **Interactive Elements**: Hover effects, mobile navigation, and form handling
- **Optimized Performance**: Lightweight and fast-loading

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **Services**: Showcase of 6 key services with icon cards
3. **Portfolio**: Featured work gallery with project previews
4. **About**: Company information with statistics
5. **Contact**: Contact form and company details with social links

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript
- No external dependencies

## Getting Started

Simply open `index.html` in your web browser to view the landing page.

```bash
open index.html
```

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    /* ... */
}
```

### Content
Update the HTML content in `index.html` to match your agency's information.

### Images
Replace the gradient placeholders in the portfolio section with your own project images.
